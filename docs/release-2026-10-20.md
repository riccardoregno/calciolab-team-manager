# Preparazione rilascio web e mobile — 20 ottobre 2026

## Modifiche incluse

- Gol subiti individuali, porte inviolate, media per 90 minuti e copertura dei dati dei portieri; confronti senza premiare dati mancanti.
- Stato dei salvataggi locali e online, recupero alla riconnessione e bozza delle statistiche partita.
- Dashboard con azioni sui dati da completare; ricerca e preferiti personali nei menu.
- Aggiornamento condiviso di statistiche e obiettivi stagionali, navigazione web/mobile e banner installazione.
- Procedura nativa multipiattaforma: wrapper Gradle Windows/Unix, controllo preventivo di macOS per iOS e normalizzazione dei percorsi Swift dopo la sincronizzazione Capacitor.
- App Links Android per calciolab.org e www.calciolab.org, mantenendo il dominio precedente.

## Controlli eseguiti

- Test JavaScript e persistenza: superati, inclusi memoria locale piena e recupero.
- ESLint: superato; nuovo script di release verificato anche separatamente.
- Build web e mobile: superate. Sincronizzazione Capacitor Android/iOS: superata, sei plugin.
- Android: assembleDebug, testDebugUnitTest e assembleDebugAndroidTest superati. Il test unitario nativo è dimostrativo; i test strumentali sono compilati, non eseguiti.
- Certificato di firma Android: impronta SHA-256 coerente con public/.well-known/assetlinks.json. Verificare separatamente la chiave App Signing se distribuita da Google Play.
- Audit npm produzione: nessuna vulnerabilità alta o critica; avvisi moderati nella catena jsPDF/DOMPurify, senza correzione proposta dal registro. Non risultano utilizzi di jsPDF.html o IN_PLACE nel sorgente.
- Flussi browser dei componenti aggiornati già verificati con backend simulato: convocazioni, presenze, salvataggi offline/online, statistiche, portale e preferiti a larghezze desktop/mobile.

## Limiti aperti

- La pubblicazione non è attestata da questo documento. Seguire CI e Deploy su GitHub fino al completamento e verificare il sito servito.
- Release Android firmata: tentativi con cache originale e separata e compilatore separato fermati da AccessDeniedException in Java ZIP filesystem durante la chiusura dei JAR; ripetere da terminale normale. Nessun AAB/APK release nuovo è stato certificato.
- Nessun dispositivo o AVD disponibile per il collaudo funzionale nativo. Provare avvio, ripresa, tastiera, Indietro, safe area, PDF, offline/riconnessione e link.
- iOS: progetto sincronizzato; archive e test richiedono macOS/Xcode. Completare firma, Associated Domains e Apple Team ID: il file apple-app-site-association contiene ancora un segnaposto. Non inventare l'identificativo.
- Le versioni native non sono state incrementate senza conoscere l'ultimo codice accettato dagli store: Android 1.1.0 / code 2; iOS 1.0 / build 1. Prima dell'invio scegliere un codice non ancora usato e verificare l'allineamento delle versioni.
- Collaudo aggiornato sui dati reali, TestFlight e pubblicazione Play/App Store ancora da completare. Non modificare dati della squadra per simulare un test.

## Comandi di rilascio

```sh
npm test
npm run lint
npm run build
git push origin main
# Attendere CI e Deploy, poi verificare https://www.calciolab.org

npm run release:android
npm run release:android:apk
# Su un Mac configurato con Xcode e firma:
npm run release:ios
```

I comandi deploy:android e deploy:ios aggiornano soltanto gli asset del progetto nativo: non caricano l'app negli store. I preferiti restano personali per account e squadra sul singolo dispositivo.
